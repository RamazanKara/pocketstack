# README demo provenance

`pocketstack-demo.gif` is a deterministic product demonstration generated by
`npm run readme:demo`. It is composed from PocketStack's real landing-page
screenshots and the exact compatibility language used by the Action.

Sources:

- `scripts/readme-demo/index.html` — deterministic animation scene;
- `web/site/assets/storefront-preview.webp` — Pocket Supply storefront;
- `web/site/assets/sprint-board-preview.webp` — Northstar sprint board;
- `web/site/assets/analytics-preview.webp` — Clearview analytics;
- `web/site/fonts/inter.woff2` — PocketStack's self-hosted interface font.

The generator captures the scene at 960×540 and 8 frames per second, then uses
FFmpeg to create a looping GIF and a WebP poster. It does not use generated
claims, mock customer data, or third-party product imagery. The manifest records
the dimensions, sources, exact claims, byte sizes, and SHA-256 checksums.
