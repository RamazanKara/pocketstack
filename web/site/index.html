04

One workflow file

Add it once. Every eligible PR gets a URL.

Keep your existing Compose file. The Action checks out the pull request, reports compatibility, and deploys only generated static files.

.github/workflows/pocketstack.yml
name: PocketStack Preview
on:
  pull_request:
    types: [opened, synchronize, reopened, closed]

permissions:
  contents: read
  pull-requests: write

jobs:
  preview:
    runs-on: ubuntu-latest
    steps:
      - uses: ramazankara/pocketstack@v1
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          compose-file: compose.yaml
          cloudflare-project: my-app-previews
          cloudflare-account-id: ${{ secrets.CLOUDFLARE_ACCOUNT_ID }}
          cloudflare-api-token: ${{ secrets.CLOUDFLARE_API_TOKEN }}

What the Action does

  1. 1
    Checks compatibilityEvery service gets a visible adapter status.
  2. 2
    Generates static outputNo Docker daemon or application code runs in CI.
  3. 3
    Posts one stable PR linkUpdated on each push; replaced with a tombstone when closed.
